# 005. Majority Element

- **Platform**: LeetCode
- **Problem Number**: #169
- **Difficulty**: Easy
- **URL**: [LeetCode #169 - Majority Element](https://leetcode.com/problems/majority-element/)

---

## Problem Statement

Given an array `nums` of size `n`, return *the majority element*.

The majority element is the element that appears **more than $\lfloor n / 2 \rfloor$ times**. You may assume that the majority element always exists in the array.

---

## Examples

### Example 1
```text
Input: nums = [3,2,3]
Output: 3
```

### Example 2
```text
Input: nums = [2,2,1,1,1,2,2]
Output: 2
```

---

## Constraints

- $n == \text{nums.length}$
- $1 \le n \le 5 \times 10^4$
- $-10^9 \le \text{nums}[i] \le 10^9$

---

## Follow-up

Could you solve the problem in linear time $\mathcal{O}(N)$ and in $\mathcal{O}(1)$ space?

# 004. Contains Duplicate

- **Platform**: LeetCode
- **Problem Number**: #217
- **Difficulty**: Easy
- **URL**: [LeetCode #217 - Contains Duplicate](https://leetcode.com/problems/contains-duplicate/)

---

## Problem Statement

Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

---

## Examples

### Example 1
```text
Input: nums = [1,2,3,1]
Output: true
```

### Example 2
```text
Input: nums = [1,2,3,4]
Output: false
```

### Example 3
```text
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

---

## Constraints

- $1 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$

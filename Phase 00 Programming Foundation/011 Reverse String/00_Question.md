# 011. Reverse String

- **Platform**: LeetCode
- **Problem Number**: #344
- **Difficulty**: Easy
- **URL**: [LeetCode #344 - Reverse String](https://leetcode.com/problems/reverse-string/)

---

## Problem Statement

Write a function that reverses a string. The input string is given as an array of characters `s`.

You must do this by modifying the input array **in-place** with $\mathcal{O}(1)$ extra memory.

---

## Examples

### Example 1
```text
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

### Example 2
```text
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

---

## Constraints

- $1 \le \text{s.length} \le 10^5$
- `s[i]` is a printable ascii character.

# 075. Palindrome Linked List

- **Platform**: LeetCode
- **Problem Number**: #234
- **Difficulty**: Easy
- **URL**: [LeetCode #234 - Palindrome Linked List](https://leetcode.com/problems/palindrome-linked-list/)

---

## Problem Statement

Given the `head` of a singly linked list, return `true` *if it is a **palindrome** or `false` otherwise*.

---

## Examples

### Example 1
```text
Input: head = [1,2,2,1]
Output: true
```

### Example 2
```text
Input: head = [1,2]
Output: false
```

---

## Constraints

- The number of nodes in the list is in the range $[1, 10^5]$.
- $0 \le \text{Node.val} \le 9$

---

## Follow-up

Could you do it in $\mathcal{O}(n)$ time and $\mathcal{O}(1)$ space?

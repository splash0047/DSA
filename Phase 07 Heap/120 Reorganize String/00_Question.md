# 120. Reorganize String

- **Platform**: LeetCode
- **Problem Number**: #767
- **Difficulty**: Medium
- **URL**: [LeetCode #767 - Reorganize String](https://leetcode.com/problems/reorganize-string/)

---

## Problem Statement

Given a string `s`, rearrange the characters of `s` so that any two adjacent characters are not the same.

Return *any possible rearrangement of* `s` *or return* `""` *if not possible*.

---

## Examples

### Example 1
```text
Input: s = "aab"
Output: "aba"
```

### Example 2
```text
Input: s = "aaab"
Output: ""
```

---

## Constraints

- $1 \le \text{s.length} \le 500$
- `s` consists of lowercase English letters.

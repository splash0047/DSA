# 153. Number of 1 Bits

- **Platform**: LeetCode

## Problem Statement

Write a function that takes the binary representation of a positive integer `n` and returns the number of set bits (also known as the [Hamming weight](https://en.wikipedia.org/wiki/Hamming_weight)).

---

## Examples

### Example 1
```text
Input: n = 11
Output: 3
Explanation: The input binary string 1011 has a total of three set bits.
```

### Example 2
```text
Input: n = 128
Output: 1
Explanation: The input binary string 10000000 has a total of one set bit.
```

### Example 3
```text
Input: n = 2147483645
Output: 30
Explanation: The input binary string 11111111111111111111111111111101 has a total of thirty set bits.
```

---

## Constraints

- $1 \le n \le 2^{31} - 1$
